# 路线图

> 于 2026-09-04 从 issue #4 迁移而来。Issue 用于 bug 报告与功能请求；路线图存放在这里。要认领某一条目，请开一个引用它的 issue。

## 我们目前所处的位置

- **7 个平台** — OpenClaw、Codex、Claude Code、Hermes（SQLite）、OMP、DeepSeek Harness 与 Gemini CLI，均从其原生日志格式解析
- **会话浏览器**，支持工具调用检查、trace/瀑布视图、spawn 追踪与消息时间线
- **Prompt 工具链** — 提取（已过滤噪音）、带结果归因的模板聚类、由 Claude 驱动的改写
- **跨全部平台的全局搜索**、洞察面板
- **React + Vite 前端**，由 Express 后端服务；基于 Node 内置运行器的 400+ 测试（`npm test`，2026-11-01），CI 运行于 Node 22
- **统一会话状态** — 由记录证据推导的四态模型（`awaiting-input` / `working` / `waiting` / `stopped`），被侧栏、任务看板视图、SSE 实时尾随与终端 CLI 共享；时间窗口可配置
- **自定义平台适配器** — 把一个 JavaScript 适配器放进 `~/.agentlray/platforms/` 即可接入平台，无需触碰源码；启动时校验，坏文件绝不阻塞启动
- **全部内置平台均可续跑** — `codex` / `claude-code` / `omp` / `dsh` / `gemini` / `hermes` 可从 CLI 或复制按钮原生续跑，可配置可执行文件解析；全程支持 Windows（PowerShell 引用、`%USERPROFILE%` 家目录）
- **白天/黑夜主题、统一设置文件** — 日/夜主题切换；所有服务端设置聚合在单个 `~/.agentlray/settings.json`，位于一个 `GET/PUT /api/settings` 之后
- **有证据支撑的失败事件与本地复核**，支持完整结果失效、证据导航与窄屏会话布局

## 当前优先级

产品方向是**为你已经在使用的编码 agent 提供本地执行证据**：实际运行了什么、哪些结果支撑一个结论、以及日志无法确立什么。自动事实优先；人工标签可选。原生 agent 越来越多地内置仪表盘、用量指标与工作流进度，因此泛化的统计并非差异点。Star、下载量与截图本身并不确立有用性。

外部佐证：官方指引强调[可执行验证](https://code.claude.com/docs/en/best-practices#give-claude-a-way-to-verify-its-work)、[后台子 agent 工作流](https://code.claude.com/docs/en/workflows)与[协调/续跑限制](https://code.claude.com/docs/en/agent-teams)。这些是能力与工程约束，而非市场规模证据。用户 issue 报告与厂商已修复的 bug 是研究输入，而非永久产品缺口的证明。

| 优先级 | 目标 | 验收标准，而非承诺 |
| --- | --- | --- |
| P0 | 让新工作流立即可测 | 一个仅供演示的入口打开一个明确为合成的用例：2 个事件里 7 条待处理记录，全部证据可访问，本地复核不改写自动结果。保留既有的默认演示与样例。 |
| P1 | 当前会话复核可移植性落地 | 仅预览导入与显式明文下载；精确的身份/证据匹配、无覆盖、有界的 schema 与部分失败报告。用合成迁移验证并在 CI 后发布；全历史备份与路径重映射仍属范围外。 |
| P2 | 执行/验证证据，而非又一个统计面板 | 自动健康与修改/检查时序区分前后/交叠/之后及未知结果。Codex 进程 ID 现可在不改写历史或原始检查起点的情况下连接启动/轮询/退出证据。下一步调研显式任务/子链接与分步结果；拒绝歧义关联，而不是放宽 shell 假设。确定性测试与冻结日志检查不是文件覆盖率、人类节省的时间或普适准确率。 |
| P3 | 让发布对贡献者可复现 | 保持干净安装测试、生成的 fixtures、文档声明与发布/包验证一致。当浏览器回归自动化能在不依赖个人日志的情况下确定性地运行时再添加上。 |

### 机器可消费的证据

集成表面是一个只读的离线 CLI，而非 MCP、一个新的 agent 运行时或托管服务。`inspect` 使用与 UI 相同的生成规则输出带版本的 facts 与源引用。版本 1.24.0 提供 `--summary --json`、显式哈希校验且字节有界的 `evidence`，以及结构化 JSON 失败。完整成功的报告保持兼容；消费者必须处理新的错误信封。显式退出策略与覆盖率失败绝不可变成一个泛化的“任务通过”声明。当前范围是一个稳定的 Codex/OMP/Claude Code JSONL 文件；无自动发现或命令执行。原始证据扩展为选择加入，可能暴露敏感内容。[分层契约](offline-inspect.md#layered-cli-summary-first-evidence-on-demand)。

不承诺任何发布日期或 star 数目标。进度以这些可观察结果为准。物理设备/键盘覆盖率与复杂的 Trace/分析布局仍是独立工作，不由会话屏检查所隐含。

## 非目标（现阶段）

- 会话数据的云同步或任何服务端存储 — AgentLRay 保持为对你自己的日志的本地、只读查看器
- 插件市场 — 在格式数量证明有必要之前，适配器都并入仓库内
